What this prototype is, honestly

The logic is real

Expiry is computed from join date plus plan length. Reminders fire at exactly 2 days. The nightly report sums balances and lists who expires this week. Change a member's date and the whole thing reacts.

WhatsApp is not

Messages are composed and logged, not sent. The official Business API needs Meta approval and per-message pricing; unofficial libraries get numbers banned. That integration is the actual work, and the real cost.

No n8n required

The original reel sells an n8n workflow. Same result, less dependency: a cron job, a database and an API call — which is also what tools/reminders.py in this repo demonstrates.
